## ✨ Features | ویژگی‌ها

- 📊 **Live Dashboard** — Real-time player count, server time & one-click Discord invite copy
- 🚨 **Heists Module** — Track 8+ active heists: Bank, Mini Bank, Feelca Bank, Maze Bank, Shop, Bimeh, Mythic & Cargo
- 👮 **Jobs Module** — Live status of military & government organizations (Army, Police, Judiciary, EMS, Doctor & more)
- 🌍 **Bilingual UI** — Full Persian (RTL) & English support
- 🎨 **Modern Dark Theme** — Clean, glassy UI with smooth animations
- ⚡ **Lightweight & Optimized** — Low resource usage, 0.00ms idle
