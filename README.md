## 🚀 Installation | نصب

1. **Download:**
   - Click the **[Download Latest Release](https://github.com/Ali-sv/AliSv_Scoreboard/releases/latest)** button to get the files.
   - Or clone via terminal:
```bash
git clone https://github.com/Ali-sv/AliSv_Scoreboard.git
```

2. **Setup:**
   - Place the `AliSv_Scoreboard` folder inside your server `resources` directory.
3. **Configuration:**
   - Add the following line to your `server.cfg`:
     ```cfg
     ensure AliSv_Scoreboard
     ```
4. **Restart:**
   - Restart your server or type `refresh` and `ensure AliSv_Scoreboard` in your server console.
